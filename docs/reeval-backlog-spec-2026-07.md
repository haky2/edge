1. **백엔드** `POST /signal-usage` — 앱이 action_log(매매 기록)를 보냄(판단대조 JudgmentComparison의 기존 POST 패턴 재사용). 서버가 signal_fired.jsonl과 조인: 신호 발화 후 5거래일 내 같은 종목 매매 있으면 "행동", 없으면 "미행동". 신호 종류별 집계: 발화 수·행동률·행동분 20거래일 초과수익 vs 미행동분(JudgmentComparison 채점기 재사용, 코스피 0001 대조).
2. 표본<15 침묵(캘리브레이션 원칙 그대로), 중립 밴드 주의사항 명시(통계 감사 교훈).
3. **클라**: 내 패턴 탭에 "신호 실사용" 섹션(iOS+Android) — 종류별 행동률·성적. 행동률 낮고 성적 무근거인 신호는 "알림 끄기 후보" 라벨(끄는 건 수동 결정).

**검증**: 유닛(조인 윈도·집계) + 합성 signal_fired로 로컬 검증(투자 데이터 백업 후 복구 — ①-(a) 방식).

## R5. 상세 델타 스트립 + 카드 접힘 (Sonnet)

**배경**: 상세 화면 카드 12+·코멘트 내 메타 3종 — 병목은 "아침에 읽는 시간". 전면 개편 대신 점진: "전일 대비 달라진 것"을 최상단 한 줄 스트립으로, 정적 카드들은 기본 접힘.

**스코프**:
1. **백엔드**: `/analysis/{code}` 응답에 `deltaLines: List<String>` 추가(계산만, LLM 0) — 재료: prevStance→stance 전환 여부(기존 필드), 목표가 이벤트(90일 상향/하향 최근 발생), regime 라벨 변화(전일 캐시 대비 — stance_log의 regime 활용), (N3-a 이후) 당일 신호 발화. 각 항목 "달라진 것 없음"이면 빈 리스트.
2. **클라**: 상세 최상단(시세 카드 아래)에 델타 스트립 — deltaLines 있을 때만, 없으면 미표시. 유사국면·배당·기술지표·수급 카드 기본 접힘 전환(CollapsibleCard/DisclosureGroup — initiallyExpanded=false), AI 코멘트·포지션·재료는 펼침 유지. iOS+Android 동시.

**검증**: 양앱 빌드 + 시뮬(스탠스 전환 종목에서 스트립 표시·무변화 종목에서 미표시) + 접힘 상태 확인. 배경/섹션 색 정책(edge-bg-section-policy) 준수.

## N4. 시나리오 스트레스 — 축소판 (Opus)

**배경**: 리스크 카드의 다음 질문 "코스피 -10%면 얼마 잃나". 원안의 매크로 샥 전파는 SENSITIVITY 실측(지지 6·반증 5·**무근거 15**)과 충돌 — 무근거 지표로 시나리오 표를 만들면 그럴듯한 거짓말로 회귀. **실측 지지 축만**: 베타(전 종목 실측) + 나스닥 동조(61~71% 실측). 환율·유가·구리 샥은 제외.

**스코프**:
1. **백엔드** `POST /portfolio-stress` — 시나리오: 코스피 −5%/−10%/+5% × 종목별 실측 베타(PortfolioRiskService 재사용) → 종목·포트 예상 손익. 상관 클러스터(r≥0.7) 동반 하락 금액 별도 표기("분산돼 보여도 같이 무너지는 조합"). LLM 0. caveat 고정: "조건부 산수이며 예측이 아닙니다. 베타는 60거래일 실측값으로 국면에 따라 변합니다."
2. **클라**: 내 자산 탭 리스크 카드 아래 접이식 "스트레스 시나리오" 표. iOS+Android 동시.

**검증**: 유닛(베타 전파 항등식·클러스터 합산) + 실호출(현 포트) + 양앱 빌드·시뮬.
