# 프롬프트 조항 다이어트 — 2026-07 (R6)

재평가 백로그 R6. facts 다이어트(-22.1%) 방법론을 규칙 계열에 적용 — 단 실측 없이 합치지 않는다는
원칙(리뷰 검증에서 C10/C11 중복 주장이 과장으로 판정된 교훈)을 지켰다. **이 문서가 R6 정본.**

## 결론 요약

- 제거된 조항: **0개** — 초기 휴리스틱 중 실측으로 대체된 뒤 남은 잔재는 없었다(전수 확인).
- 통폐합: **같은 프롬프트 안에서 실측 서술이 2번 들어가던 중복 2건** 해소(A3↔C14, ASK 공격 스탠스↔Q11).
- 위치 교정: 규칙 번호 누출 금지 지시가 조건부 조항(C18·Q13) 안에 파묻혀 있던 것을 형식 조항(C3·Q2·P7)으로
  이동 — 기존에는 장기 계좌가 아니면 이 지시 자체가 "없으면 무시" 범위에 들어 통째로 무시됐다.
- 번호 상호참조 자연어화 5곳 — "(C17)" 단독 괄호 누출 실사고와 같은 계열의 위험 제거(R4 스모크 패턴 ② 감시 대상).
- 조립 프롬프트 크기: 공격 분석 **10,369 → 10,161자(-2.0%)**, ask 공격 **3,183 → 3,138자(-1.4%)**,
  방어 분석·ask 방어는 ±0. 절감량 자체는 완만 — 이번 다이어트의 실익은 글자수가 아니라
  **실측 규율의 정본이 프롬프트당 1곳으로 통일**된 것(레벨 앵커 실측이 바뀔 때 수정 지점이 절반).

## 변경 내역

### 1. A3 중복 제거 (608→397자)
AGGRESSIVE_PROMPT = AGGRESSIVE_CORE + COMMON_RULES 조립이라, A3와 C14가 **같은 프롬프트 안에서**
실측 서술(돌파=모멘텀 관심 종목군 한정·저점 반등 기각·이평 기각)을 문장 단위로 중복했다.
A3는 앵커 목록·괄호 명시·폴백(조건 대체)만 남기고, 실측 방향 한정은 "아래 공통 규칙의
지지선·저항선·매매 레벨 조항을 그대로 따르라 — 공격 모드에서도 실측 한정이 우선한다"로 위임.
번호 참조 없이 조항 이름으로 참조(계좌 슬라이스 교훈: 항목 이름으로 풀 것).

### 2. ASK 공격 스탠스 중복 제거 (589→534자)
ask 공격 프롬프트(ASK_CORE + 스탠스 블록)도 Q11과 스탠스 블록이 같은 실측 서술을 중복. 동일 방식 위임.

### 3. 규칙 번호 누출 금지 일반화
- C18·Q13 안의 "규칙 번호는 내부 지시일 뿐 본문에 쓰지 마라" 문장 제거.
- C3(분석)·Q2(ask)·P7(포폴) 형식 조항에 동일 문장 추가 → 전 모드·전 트리거 적용.
  P 계열엔 기존에 이 방어가 아예 없었다.

### 4. 번호 상호참조 자연어화 (5곳)
- C12 "(C1은 논지 텍스트에도…)" → "(사실 한정 규칙은 논지 텍스트에도…)"
- C13 "(C1은 직전 기록에도…)" → "(사실 한정 규칙은 직전 기록에도…)"
- C16 "변천 속 텍스트에도 C1을 적용하라" → "변천 속 텍스트의 수치·주장도 근거로 인용하지 마라(사실 한정 규칙 그대로)"
- C18 "(C17 등)" 문장 자체 제거(위 3번)
- P8 "(P1은…)" → "(사실 한정 규칙은…)"

### 5. 검토 후 유지(합치지 않음)
- **C10 ↔ C11**: 재확인 결과 다른 축 — C10은 국면 판정 항목이 없어도 적용되는 밸류 해석 균형 일반론
  (목표가 추세·동종 상대·표본 신뢰도), C11은 "국면 판정(계산)" 항목 존재 시의 프레임 지정. 리뷰의
  중복 주장은 과장 판정 유지.
- **C9 ↔ C15**: 통계 과신 금지 vs 재료 단기 방향 금지 — 다른 축.
- **C↔Q 교차 중복**(C6↔Q4·C8↔Q8·C9↔Q6·C14↔Q11 등): 프롬프트가 서로 달라(분석 vs ask) 자체완결이
  의도 — 같은 프롬프트 내 중복이 아니므로 다이어트 대상 아님.
- **D·A 계열의 실측 이전 레벨 휴리스틱 잔재**: 전수 확인 결과 없음(C14 도입 시 이미 정리됨).
