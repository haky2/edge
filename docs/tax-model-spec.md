# 세후 실질 수익률 — 간이 세제 모델 스펙 (D1, 2026-07-16)

"내 자산" 탭에 보여줄 **세후 실질 평가손익**의 계산 경계 정의. 구현은
`sharedLogic/analysis/TaxEngine.kt`(순수 계산, LLM·백엔드·네트워크 없음), 테스트는 `TaxEngineTest`.

## 프레임: "지금 전량 매도하면" 시나리오

앱이 가진 데이터는 **미실현 평가손익뿐**이다(계좌별 평단·수량·현재가). 실현손익 원장·배당
수취 내역·연간 거래 이력이 없으므로 "연간 세금 정산"은 계산할 수 없고, 하는 척도 하지 않는다.
계산하는 것은 단 하나 — **오늘 전량 매도를 가정했을 때의 세후 손익**. 이 프레임을 카드에 명시한다.

## 계산 룰 (2026-07 현행, 출처는 하단)

| 계좌 × 자산 | 처리 |
|---|---|
| 일반·ISA × 국내 | 매매차익 **비과세**(소액주주). 매도 시 **증권거래세 0.20%를 매도가액 전체에** 부과 — 손실 종목을 팔아도 낸다. 2026-01-01부터 코스피(0.05+농특 0.15)·코스닥(0.20) 동률이라 시장 구분 불필요 |
| 일반 × 해외(`US:`) | 보유 해외 종목 **손익통산** → 연 250만 기본공제 → 과세표준 3억 이하 22%, 초과분 27.5%(지방세 포함). 통산 결과 음수면 세금 0 |
| ISA | 국내 매매차익 기준으론 **일반과 동일**(원래 비과세 + 거래세 동일 부과). ISA 비과세 한도(200/400만, 상향 개정 진행 중)는 배당·이자 대상인데 앱에 그 데이터가 없음 → 카드에서 이 사실을 정직하게 안내(흔한 오해 교정) |
| IRP·퇴직연금 | **과세이연 — 숫자 계산 제외.** 현재 세금 0이지만 "세후 확정"이 아니라 인출 시점 과세(수령 방식에 따라 세율이 달라짐). 인출 세액은 계산 불가 → 평가손익만 분리 표시 + "인출 시 과세" 안내. 세율 숫자 창작 금지 |

## 계좌 타입 추론

`AccountRepository.presetHorizon`과 같은 원칙 — **프리셋 이름 정확 매칭만, 커스텀 이름은 추론하지 않는다**:
- `"ISA"` → ISA / `"IRP개인연금"`·`"퇴직연금"` → 연금 / 그 외(커스텀 포함) → 일반
- 커스텀 이름 계좌(예: "미래에셋 IRP")는 일반으로 계산됨 — 카드가 **계좌별 적용 타입을 노출**해서
  사용자가 오분류를 눈으로 확인할 수 있게 한다(잘못 계산을 조용히 보여주는 것 방지).

## 명시적으로 계산하지 않는 것 (면책 목록 — 카드 footer·스펙 공용)

1. **배당·이자 소득세(15.4%, 2026 분리과세 개편 포함)** — 배당 수취 데이터 없음.
2. **대주주 양도세** — 소액주주 가정(종목당 보유액 기준 미달 전제).
3. **250만 공제의 연간 소진분** — 올해 이미 실현한 해외 양도차익을 앱이 모름 → 공제 전액
   사용 가능 가정(실제보다 세금 과소계상 가능성을 면책에 명시).
4. **ETF 거래세 면제** — 코드만으로 ETF/주식 구분 불가 → 전 종목 주식 가정(ETF 보유 시
   거래세 과대계상). 연금 계좌는 어차피 숫자 계산 제외라 무관.
5. **증권사 매매 수수료·해외 환전 스프레드·SEC fee** — 세금이 아님, 증권사별 상이.
6. **연금 인출 세액** — 수령 시점·방식(연금/일시금)·연간 수령액에 따라 3.3~16.5% 가변,
   단일 숫자로 창작하지 않는다.

## 엣지 케이스 규정

- **해외 포지션은 현재 앱에서 입력 불가**(OverseasDetailView에 포지션 UI 없음) — 그러나
  `holding.code`에 제약이 없어 장래 지원 시 들어올 수 있으므로 엔진은 `US:` 분기를 정확히
  구현한다. 조용히 국내 룰(거래세+비과세)을 적용하는 오답 방지가 목적.
- ISA·연금 계좌의 `US:` 포지션: 현실에서 성립 불가(해외 개별주 편입 불가)지만 방어적으로 —
  ISA는 일반 해외 룰로 통산에 합류, 연금은 과세이연 그대로.
- avg_price 또는 qty가 null인 행(포지션 미입력 관심 편입)은 계산 제외.
- 세액은 원 단위 반올림.
